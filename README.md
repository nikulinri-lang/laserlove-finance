# Laser Love Finance

Отдельная веб-система для зарплаты, кадров и помощника бухгалтера Laser Love.

## MVP
- сотрудники и оклады
- табель
- расчёт зарплаты
- НДФЛ и страховые взносы (расчётные правила отделены от интерфейса)
- отпуска и больничные
- закрытие месяца
- Excel-экспорт
- журнал операций
- подготовка обмена с 1С

## Стек
- Backend: Python + FastAPI
- Frontend: React + TypeScript
- Database: PostgreSQL
- Deployment: Docker

> Налоговые правила и форматы 1С перед вводом в эксплуатацию должны быть отдельно проверены по действующим требованиям РФ.
